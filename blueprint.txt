当前目标：
1. 采集「地下城通关」操作 + 画面状态（YOLO 结构化特征）
2. 按「地下城 × 角色」训练过图小模型（该图自然键频次就是监督，不按键做均衡）

4. 待补充

参数：
- 游戏窗口 = 整窗客户区（一次截图，OCR + YOLO 共用）
- 截图间隔 / YOLO 版本 / conf / iou（GUI；间隔默认 0.05s）

主流程：
对齐窗口 → 选角色 → 开始
- 采集模式 → 立刻写 PNG + 键盘 + YOLO（必须管理员；3 秒无新按键删段）。
- 自动化模式 → OCR 进图后占位（过图小模型尚未接入）
- 回城 → 只停自动化（采集靠点停止）
- FSM测试 → 不 OCR、不落盘，实时检测预览

采集（唯一写盘路径）：
- 键盘线程 + 截图落 PNG + 写盘队列
- 产出：PNG → `images/<时间戳>/`；`meta.json` / `keys.jsonl` / `frames.jsonl` → `recordings/<地下城>/<时间戳>_<角色>/`
- frames: t_ns, png, player_xy, mon_xy, loot_xy, gate_xy, boss_xy, 计数, infer_ms（截图完成后打 t_ns，再跑 YOLO）
- keys: t_ns, press|release, key
- 采集当场 YOLO。组集仍只应用 TRAIN_ALIGN 已确认清洗。
- 导出过图训练集：python export_dataset.py → dataset_export/（不改原始 jsonl；y=held_frac）
