注：进图 = OCR 区域检测到地下城关键词（原进图逻辑）。
    当前帧无地下城关键词则沿用上一帧的关键词结果（缺帧粘滞，抗单帧漏检），再进入进图/回城规则。
    回城不需关键词：连续无地下城关键词达 tn_s 秒即回城（默认 30，用 t_ns 差算秒，不换帧）。
    OCR 小框子串「返回城镇」（分数门槛同 ocr_conf）：连续命中累计 ≥ tn_s 后点按一次 F10（全局点按 ms，不进技能表）。文案消失清零并可再触发；已按后文案仍在则冷却不连按。与无关键词回城并存。
    卡住监测是全局最高优先级，可打断任何方法的原子执行；命中后状态改为【卡住】。
    计时按本帧流程状态标签：仅当标签相对上一帧变化时重置；同一标签方法重入（含前进/走近超时重入）继续累加。不因 method_timeout 重置。states.jsonl 分段规则不改。

    改 MON/BOSS 补正后旧 skill_features 作废，须重提；改 LOOT/GATE 不必重提。
E / F（提取：群单阈值、假释放效率；主面板可调）

前进超时（方法开始计时；字段 advance_timeout_ms，默认 3000，须>0；超时结束本次前进并重入判定）

走近超时（范围外走近开始计时；字段 approach_timeout_ms，默认 3000，须>0；超时结束本次走近并重选技能，不进卡住、不强行 CAST/CD）

CAST转身：仅当无需走近（已在范围→CAST）才算左右脸；点按方向键（全局点按 ms）后立即释放；要走近（HOLD）不算朝向（走本身转脸）。朝向目标用当前帧 enemy_xy 均值（_pack_center），缺检再退 _dist_center；不与走近范围中心绑定。无上下脸。

流程如何执行（由状态触发 不可短路 不可覆盖等上一个执行完；【卡住】除外，见下）
前进：
    方法
        1.确认方向（并非用于前进 而是用于过门）        
            一次性 根据玩家相对门的坐标来计算 并记录方向
            （X+/X-/Y+/Y- 每个方向用0/1即可）
        2.前进
            每帧判定 根据玩家相对门坐标来计算
            X轴
                距离是否大于GX（可调参数 默认50px）？
                是 继续接近（点按该轴方向 → 等 TH 毫秒 → 按住；TH 默认等于连按间隔，字段 th_ms）
                否 停止X轴移动
            Y轴
                距离是否大于GY（可调参数 默认10px）？
                是 继续接近（同上：点按 → TH → 按住）
                否 停止Y轴移动
            （X/Y轴同时进行 如果门消失 直接进入过门状态）
            方法开始计时；超过 advance_timeout_ms 则结束本次接近、回到状态判定（重识门/重记过门方向）。已进入过门（AX/AY）或本帧将进过门（贴门/门消失）不超时、不重记方向。同标签不重置卡住计时。连续超时达 advance_timeout_esc_n 次点按 ESC（全局点按 ms）并清零计数；正常过门清零。
        3.过门
            XY均停止移动后
            根据方法1记录的方向 如果需要移动的方向
                存在X+/X- 再向这个方向前进AX毫秒
                存在Y+/Y- 再向这个方向前进AY毫秒
                （AX/AY是可调参数 即之前的A拆成两个；字段 ax_ms / ay_ms）


开打：
    方法
        1.提取怪物分布 方法见（关于怪物分布判定）清CD见「关于CD重置」
        2.放技能（组）
            可用技能：技能表里已勾选快捷栏的技能（含勾了的 SPACE）+ 普攻X（无CD）
            排除CD计时中技能后
                取该怪物分布对应过图技能文件里第一个不在CD的技能（组）
                    有
                        计算玩家与当前最远的敌对单位（BOSS或MON）的距离
                        该距离是否在技能（组）范围内（优先提取 XY 框；本分布缺则其它分布同槽 XY 均值；再缺用该槽释放 rel 的最大 |dx|/|dy|。否则 range_px 圆；皆空用 default_range_x/y）
                            是->立即释放：按下技能键的那一帧按当前坐标重算朝向（只认左右脸：目标相对玩家 dx≥0 朝右，否则朝左；不算上下；无迟滞/无缓冲；朝向目标用当前帧 enemy 均值；缺检退分布中心；缺坐标则跳过转身。走近 HOLD 不算朝向。
                                先对该方向键点按一次（时长=全局点按 ms），再按对应快捷键；后等待（技能表 hold_ms，技能组见组结束时刻）
                                键位表勾【连按】：执行层打 COUNT 次点按，两次之间默认间隔 ms（可调，不进核心）
                            否->FSM显示范围异常 然后双轴走近（与前进 phase0 同：可同时按左右+上下；无过门/穿门）：
                                朝当前帧敌群中心（boss+mon）双轴 HOLD，缺检再退分布签名中心；直到本帧判定最远 MON/BOSS 已在技能范围 XY box 内再 CAST；走近不算朝向（不点 L/R），站桩 CAST 才点左右脸；
                                走近开始计时，超过 approach_timeout_ms 则结束本次走近、回到状态入口重选技能（不进卡住；不强制对该技能 CAST/CD）；
                    无（含没有过图文件）
                        FSM提示 无技能可放
                        不再看过图文件；从已勾选快捷栏里取释放时间（持续毫秒）最短的就绪技能放
                        （使用跟上面同样的距离判定方法 即范围内再释放 范围外双轴走近（同范围异常，无过门））
                快捷栏也没有就绪技能
                    移动到最近怪物坐标 释放普攻X（无CD，即按住X），持续XXX毫秒（可调参数 xxx_ms）

                

捡物：
    方法
        1.LOOT有没有在动（参数 PM：位移阈值，默认 10px；走近停距也用同一 PM）
            在动就等到不动为止（连续PT帧位移都不超过PM才判定停下，默认3，机制同 M/L/G）
            等停下开始后计时：达 PW 毫秒（pw_ms，默认 3000）仍在动 → 超时。
            超时：结束本次等待，蓝字「捡物等待超时 PW」，按当前 loot 快照继续步骤 2
            （数量>PC 则 PICK，否则依次捡）。不要无限等。
        2.LOOT数量是多少（参数PC 默认5）
            大于PC按左ALT键一键拾取
            小于等于PC：双轴移动到与 LOOT 目标重合（停距 PM，默认 10px；LOOT 消失=停止移动，换下一个）；无过门/穿门
                移动：与前进 phase0 同双轴 HOLD（可同时左右+上下；TH 消抖同前进，字段 th_ms）
        

        
关于CD重置（提取过图技能特征时）
同一次录像里若某技能释放间隔短于CD（带连续释放/多次释放标签则不算）则给该图加地图特征【CD重置】
若玩家处于带【CD重置】的图 则在参数击败BOSS数+1时重置CD
多次释放（技能表勾选）：可填 MULTI（默认2）。FSM 将该技能拆成 MULTI 份相同技能分别计 CD；提取 CD 重置检测跳过该技能。



关于怪物分布判定（可短路）
    1.有无BOSS？
        有->怪物分布添加标记【BOSS】
            记录BOSS的相对坐标（如有多个BOSS则取中心 并标记【多BOSS】）
            将记录的数据与【BOSS位置表】比对
                数据和已有数据（遍历全表取最相似的一个）差值在S_pos%内？
                    是 视为同一分布
                    否 将数据添加进【BOSS位置表】
        没有->2 
    2.有无MON？
        有->怪物分布添加标记【小怪】
            记录MON数量 
            单MON 直接存坐标
            多MON 取最小XY和最大XY计算MON范围框 同时存范围框和范围框中心坐标
            （单MON范围框为0 对齐数据结构）
            将记录的数据与【小怪分布表】比对
                两项数据和已有数据（遍历全表取最相似的一个）差值均过阈值？
                （单MON：中心用S_pos；多MON：中心用S_pos，最大最小X/Y差值（框尺寸）用S_size；均须过）
                    是 视为同一分布
                    否 将数据添加进【小怪位置表】
        无->怪物分布添加标记【异常】
            
            

关于技能数据提取（提取过图技能特征时）
1.提取条件玩家释放快捷栏技能（含SPACE）时
2.判定怪物分布（按玩家释放时计算 不可以用直接用当前FSM状态）作为分组依据（关于怪物分布判定）
3.提取按下技能（技能组按第一个技能算）键时的（MON+BOSS）总数量（记为起始MON数量） 和 每个MON/BOSS相对玩家的坐标 
    计算范围框（总数量>1时）：取MON/BOSS最小XY和最大XY即可画出（相对）
4.技能（组结束时刻见关于技能组）持续时间结束后（非BOSS房间） 识别剩余MON数量 和 坐标
    计算（起始MON数量-剩余MON数量）/起始MO数量N=效率值 （起始MON数量-剩余MON数量）>E 则为 群 否则为 单
    BOSS房间不算效率/群单/假释放；仍保留 killed_mon（以防某图 BOSS 房有小怪）
5.排除假释放（非BOSS房间） F%：杀MON效率低于 F（默认20）单独标记【假释放】 不计入技能序列/范围/CD
6.提取技能（组）范围
    如果效率值=100% 用步骤3提取的范围框即可 效率不足100%暂时不计范围
    再用该怪物分布分组中技能范围最大值（暂定 后面看要不要切尾）作为该怪物分布下该技能的范围
7.排序 BOSS房间按释放次数从高到低 MON房间按效率值从高到低（如果效率值相同则按释放次数比率从高到低）
（新增 技能组：如果前一个技能的释放等待时间未结束就放了第二个技能 则两个技能合并为技能组）



关于技能组：
1.定义
    前一个技能的 hold_ms 未结束就按下第二个技能 → 合并为技能组。
    组内可继续追加（第三个、第四个），规则相同。
    单技能 = 长度为 1 的组，数据结构与组完全相同
2.组标识
    group_key = 技能名按释放顺序拼接，如 "a>b>c"。有序，a>b 与 b>a 不同组
3.组结束时刻
    (组内每个技能的 按下时刻 + 该技能 hold_ms)取最大值
4.CD
    CD 表按技能维护，不存在组上。
    组可用 = 组内所有技能均就绪
5.补：关于技能组技能释放间隔
    组的记录里存 gaps_ms = 提取时[a→b 的间隔, b→c 的间隔]，跨多次释放取中位数。FSM 按这个复现。


对于检测结果瞬时为空/不为空的补丁

（PLAYER沿用上次位置 不需要）



对于可能的卡住问题
全局监测，优先级最高，可打断方法原子执行。
连续X秒当前FSM状态不变（卡住本身不计入这条连续；字段 x_s）
    x_s 应大于 max(最长技能持续, AX, AY, PW, 卡住恢复序列 HOLD)（均换算成秒）
    状态改为【卡住】
    方法
        按配置 stuck_recover 跑一轮后结束并回到原流程（不是无限转；这不是前进，不用 GX/GY/过门）
        默认：ESC 点按（全局点按 ms）→ 右 HOLD 2×s → 左 HOLD 2×s → 上 HOLD 1×s → 下 HOLD 1×s
        基准秒 stuck_recover_s（主面板「恢复s」，默认 1）；步骤 s 为倍数。步骤也可写绝对 ms。序列在 json，改配置不必改代码。
        已知限制：默认序列净位移约 0，覆盖以原点为中心、X 单边 2s、Y 单边 1s 的十字；黑洞不在十字上则无净推进。连续 N 次卡住回城暂不做。

前进：未锁向（adv_dir_set=0）且草稿离开 ADVANCE（丢门）时黏 1 帧，第 2 帧仍无门则解除方法粘住、退出前进；已锁向丢门仍进穿门。

约定摘要：开打范围异常/捡物=双轴走近无过门；停条件分别为技能范围 XY / 与物重合（PM）；前进=GX/GY 对准后穿门。
